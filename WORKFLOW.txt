Step 1: INSTALLATION
--------------------
    Action: pip install -r requirements.txt
    Output: All dependencies installed (OpenCV, MediaPipe, scikit-learn, etc.)
    Time:   2-5 minutes

    ✓ Ready to proceed to Step 2


Step 2: DATA COLLECTION
------------------------
    Action: python collect_data.py

    What happens:
    ┌─────────────────────────────────────────────┐
    │  1. Camera opens                            │
    │  2. Prompt: Which letters to collect?       │
    │  3. For each letter:                        │
    │     - Position hand in ASL sign             │
    │     - Press SPACE to start                  │
    │     - Hold steady (100 samples collected)   │
    │     - Data saved automatically              │
    └─────────────────────────────────────────────┘

    Output: data/sign_language_data.pkl
    Time:   15-30 minutes (for A-Z)

    ✓ Ready to proceed to Step 3


Step 3: MODEL TRAINING
-----------------------
    Action: python train_model.py

    What happens:
    ┌─────────────────────────────────────────────┐
    │  1. Load collected data                     │
    │  2. Split into train/test (80/20)          │
    │  3. Train Random Forest classifier          │
    │  4. Evaluate accuracy                       │
    │  5. Show metrics and confusion matrix       │
    │  6. Save trained model                      │
    └─────────────────────────────────────────────┘

    Output: models/sign_language_model.pkl
    Time:   1-5 minutes

    ✓ Ready to proceed to Step 4


Step 4: REAL-TIME DETECTION
----------------------------
    Action: python detect_sign.py

    What happens:
    ┌─────────────────────────────────────────────┐
    │  1. Camera opens with live feed             │
    │  2. Hand landmarks overlay appears          │
    │  3. Make ASL sign                           │
    │  4. System predicts letter                  │
    │  5. Shows confidence score                  │
    │  6. Press 'q' to quit                       │
    └─────────────────────────────────────────────┘

    Output: Real-time predictions!
    Time:   As long as you want

    ✓ System fully operational!

================================================================================
                    TROUBLESHOOTING QUICK REFERENCE
================================================================================

    Camera not working?
    → Close other apps, try VideoCapture(1) instead of (0)

    No hand detected?
    → Improve lighting, move hand closer, use plain background

    Low accuracy?
    → Collect more data (200+ samples), ensure consistent positioning

    Wrong predictions?
    → Use same environment as data collection (lighting, angle)

    Predictions jittery?
    → Increase history_size in detect_sign.py

    ➡️  Full guide: See TROUBLESHOOTING.md

================================================================================
                        TIPS FOR SUCCESS
================================================================================

    1. Start Small
       → Collect just A, B, C, D, E first to test system
       → Add more letters once you're comfortable

    2. Quality > Quantity
       → Better to have 100 good samples than 200 poor ones
       → Keep hand steady, use good lighting

    3. Consistency Matters
       → Use same setup for collection and detection
       → Same lighting, camera angle, background

    4. Practice First
       → Review ASL_REFERENCE.md before collecting
       → Practice each sign before recording

    5. Test Frequently
       → After collecting each letter, verify data saved
       → Train and test with few letters before doing all 26
